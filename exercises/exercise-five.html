Exercise 05

Module 5 Portfolio Exercise

Reproducing and reconstructing an existing data visualisation using Python and an alternative colour scale.

Master Visualisation

For this exercise, I selected an existing data visualisation to reproduce as closely as possible using Python. The original visualisation was analysed in terms of its chart structure, layout, labels, colours, typography, legend and overall composition.

Exercise Summary

The first stage of the exercise involved examining the master visualisation and identifying the features that needed to be recreated. This included the chart type, axes, labels, legend, typography, spacing, colour palette and graphical proportions.

The second stage involved reproducing the visualisation in Python using the relevant dataset. The aim was to match the original as closely as possible while preserving the same underlying data and overall structure.

The final stage involved reconstructing the visualisation using an alternative colour scale. This allowed the effect of colour choice on readability, contrast and visual hierarchy to be explored without changing the underlying information.

Reproduction

The reproduction was created in Python by rebuilding the major visual elements of the master visualisation. Particular attention was given to the layout, labels, legend, colours, spacing and graphical proportions in order to create a close visual match.

Reconstruction

The reconstruction retained the same data and overall chart structure as the reproduction, but used an alternative colour scale. This allowed the influence of colour choice on the appearance and readability of the visualisation to be considered while keeping the underlying data unchanged.
