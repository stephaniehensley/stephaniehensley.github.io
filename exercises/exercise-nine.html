Title Recorded Meteorites Around the World

An interactive spatial visualisation of meteorite records by geographic position, recorded time period and mass.

Summary

This interactive spatial visualisation builds upon my Module 8 meteorite map, using NASA's Meteorite Landings dataset.

Each marker represents an individual meteorite record, positioned using its recorded latitude and longitude. Colour represents the recorded time period, while marker size represents meteorite mass.

Mapping
  • Geographic Position: Each marker is positioned using the recorded latitude and longitude of the meteorite.
  • Colour: Recorded time period, grouped into six ordinal categories: Before 1800, 1800–1849, 1850–1899, 1900–1949, 1950–1999 and 2000 Onwards.
  • Marker Size: Recorded meteorite mass represented using a logarithmic scale.

Important Notes
  • The map includes recorded meteorites within the dataset and does not show every meteorite that has ever landed on Earth.
  • Meteorites with missing latitude, longitude, year or mass were excluded.
  • Records located at (0°, 0°) were excluded due to the large number of records containing these coordinates.
  • Meteorite mass is measured in grams in the original dataset, although some legend values are shown in kilograms.
  • Marker size uses a logarithmic scale and is not directly proportional to raw mass.
  • Recorded years have been grouped into broader time periods.
  • Geographic clustering reflects recorded observations rather than the likelihood of meteorite landings.
